# Campaign Profile: <Brand / campaign name>

Copy this file to `campaigns/<name>.md` and fill it in. The director loads the matching profile for a request and applies it without being re-told. Delete lines that don't apply. Never invent brand facts: leave a bracketed placeholder instead.

## Brand
- Name, what it sells, one-line positioning
- Mark / logo: how it must look (shape, color, placement). Always attach the user's reference image; never redraw it.
- Look and tone: 3-5 observable words (not "premium" alone)

## Subjects (people, products, characters)
- Per recurring subject: 3-5 visual anchors. Reference images outrank any text here.
- Wardrobe or product: materials, colors, finish; what must be identical in every shot

## Setting
- Location, time of day, light source, surfaces, background activity. Keep identical across related clips.

## Hard rules (these beat any repo advice)
- Camera: allowed moves, height, and what is NEVER allowed unless requested (drone, zoom-out, aerial, logo reveal, text overlays...)
- Content: things that must always / never appear
- Object counts: exact numbers (e.g. "four cups total")

## Defaults
- Clip length, aspect ratio, resolution, model
- Audio: diegetic only, or music, and who adds it
